    How it works

    What's inside a Pakistani IBAN

    PKCountry
    36Check digits
    SCBLBank code
    0000001123456702Account number, padded to 16

    24 characters, always

    Every Pakistani IBAN is exactly 24 characters and starts with PK. The State Bank of Pakistan made IBANs mandatory for all accounts.

    Check digits catch typos

    The 2 digits after PK are calculated from the rest using the ISO 13616 mod-97 method. One wrong character and the IBAN fails the check.

    Zero-padded account number

    The last 16 characters are your account number with leading zeros. Some banks also include a branch or product code here.
